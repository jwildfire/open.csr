prepare_data() R function

Reads each dataset the specs name from its source lane, applies the documented derivations, and hands the prepared frames to the ARD builder; every ARD records each frame's hash and row count.

Inputs
  • vendored transport filesthe study's own package
  • the source registrydata_sources(): which lane each dataset resolves to
  • the study modelanalysis-set flags, arm labels
Function
  • prepare_data()pipeline/R/data-prep.R
Outputs
  • prepared datasetsin memory; hash and rows recorded in every ARD envelope

regenerate_values() R function

Resolves every named value's address against the committed ARDs, evaluates the declared arithmetic, and writes the store with each value's provenance.

Inputs
  • values.yamlnames, addresses, arithmetic
  • committed ARDseach display's current iteration
Function
  • regenerate_values()pipeline/R/values.R
Outputs
  • outputs/values/values.jsonvalue, formatted value, ARD row and hash

Code: pipeline/R/values.R

Produced

  • randomised-n Subjects randomised
  • treated-n Subjects treated (safety analysis set)
  • completed-n Subjects who completed the study
  • discontinued-n Subjects who discontinued
  • completed-pct Percentage of randomised subjects who completed
  • age-median-total Median age (years), all subjects
  • female-n-total Female subjects
  • ae-any-n-total Subjects with at least one adverse event
  • ae-any-n-placebo Subjects with at least one adverse event (Placebo)
  • ae-any-n-low Subjects with at least one adverse event (Xanomeline Low Dose)
  • ae-any-n-high Subjects with at least one adverse event (Xanomeline High Dose)
  • ae-any-pct-high Percentage of high-dose subjects with at least one adverse event
  • safety-n-high Subjects in the safety analysis set (Xanomeline High Dose)
  • ae-any-n-xanomeline Subjects with at least one adverse event, both xanomeline arms
  • ae-excess-high-vs-placebo Additional subjects with an adverse event, high dose versus placebo

assemble.mjs Node script

Fills a template object with this study's text, displays and values, numbers the displays from assembly order, records what each block and the document were built from, and runs the seven gates.

Inputs
  • sections.yaml + assembly.yamlthe document model and what this study puts in it
  • text blocksapproved ones, for generated prose
  • current ARDs and rendered variants
  • values.json
  • the study modelthe treatment-consistency gate
Function
  • assemble.mjsscripts/assemble.mjs
Outputs
  • docs/assembled/<document>.jsonthe document as data, with every gate's result and its inputs record
  • docs/assembled/<document>.htmlthe rendered document

Code: scripts/assemble.mjs

Gates

  • structure
  • binding resolution
  • numeric fidelity
  • cross-references
  • values
  • treatment consistency
  • display coverage

Produced

  • Clinical Study Report template ich-e3
  • Study Synopsis template e3-synopsis
  • Post-Text Display Package template display-package
  • Abbreviated Clinical Study Report (ICH E3) template e3-abbreviated
