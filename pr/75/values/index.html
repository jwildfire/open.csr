Values

Named numbers

Prose binds numbers by address today; the unit a writer reuses is a name. A value is declared once in library/values/values.yaml, resolved by the pipeline against the committed Analysis Results Data, and cited from prose as {{value:id}}. The build re-derives every one of them from the same ARDs the report is built from, so a value that has drifted from its source fails exactly the way a typed number does.
