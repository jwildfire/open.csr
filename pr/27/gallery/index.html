open.csr — an open-source Clinical Study Report builder. Numbers are computed by versioned specs, serialized as ARDs, and bound into prose that never restates them.

Demo data is CDISC Pilot 01 via pharmaverseadam · everything on this site is precomputed and static · source on GitHub · obot roadmap.
