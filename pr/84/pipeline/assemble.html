Pipeline · Node script

assemble.mjs

Fills a template object with this study's text, displays and values, numbers the displays from assembly order, records what each block and the document were built from, and runs the seven gates.

Inputs
  • sections.yaml + assembly.yamlthe document model and what this study puts in it
  • text blocksapproved ones, for generated prose
  • current ARDs and rendered variants
  • values.json
  • the study modelthe treatment-consistency gate
Function
  • assemble.mjsscripts/assemble.mjs
Outputs
  • docs/assembled/<document>.jsonthe document as data, with every gate's result and its inputs record
  • docs/assembled/<document>.htmlthe rendered document

Code: scripts/assemble.mjs

Gates

  • structure
  • binding resolution
  • numeric fidelity
  • cross-references
  • values
  • treatment consistency
  • display coverage

Produced

  • Clinical Study Report template ich-e3
  • Study Synopsis template e3-synopsis
  • Post-Text Display Package template display-package
  • Abbreviated Clinical Study Report (ICH E3) template e3-abbreviated

open.csr — an open-source Clinical Study Report builder. Numbers are computed by versioned specs, serialized as ARDs, and bound into prose that never restates them.

Demo data is CDISC Pilot 01 via pharmaverseadam · everything on this site is precomputed and static · source on GitHub · obot roadmap.
