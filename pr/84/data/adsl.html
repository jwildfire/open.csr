Derivations and notes

  • SAFFL, ITTFL and EFFFL as the study states them, blank recoded to N; no population flag is guessed.
  • Baseline weight, height and BMI and the study's own age groups (<65, 65-80, >80) as shipped.
  • RACEOR, the race-with-origin recode the reference report prints (ethnicity first, then race), added for the demographics table; the CDISC-coded RACE stays.
  • SITEID kept as a factor in the site order the reference report uses.

The preparation layer's derivations are documented in the contracts, §4.
